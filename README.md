# اوهمیک (Ohmic)

مجموعه ابزارهای تعاملی برای محاسبات قطعات و مدار در الکترونیک. هدف پروژه ساده کردن انتخاب مقادیر قطعات، مشاهده رفتار فرکانسی و طراحی سریع بدون درگیر شدن با محاسبات دستی تکراری است.

---

## ابزارهای موجود

### ۱. مقاومت‌های موازی
- محاسبه مقاومت معادل و هدایت الکتریکی کل مدار.
- تفکیک شاخه‌ها با تعداد دلخواه و نمایش سهم جریان هر شاخه به درصد.
- شماتیک برداری مدار با استانداردهای IEEE و IEC و هشدار وضعیت اتصال کوتاه.

### ۲. مقسم ولتاژ (Voltage Divider)
- تعیین مقادیر مقاومت‌های R1 و R2 بر مبنای ولتاژ ورودی و خروجی هدف.
- پیشنهاد خودکار جفت‌مقاومت‌های استاندارد تجاری (سری‌های E24 و E96) بر اساس کمترین خطا یا کمترین تلفات توان.
- امکان تعیین مقاومت بار (RL) و مشاهده افت ولتاژ تحت بار واقعی.

### ۳. فیلترهای پسیو فرکانسی (RC و RL)
- محاسبه فرکانس قطع (-3dB)، ثابت زمانی (τ) و زاویه فاز در فرکانس کاری.
- رسم دیاگرام بُد (دامنه و فاز) در ۴ دهه فرکانسی.
- پیشنهاد قطعات تجاری استاندارد نزدیک به فرکانس قطع مورد نظر.

## اجرا و توسعه محلی

```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه
npm run dev

# بیلد پروژه
npm run build

# بررسی کدها با لینتر
npm run lint
```

پس از اجرای `npm run dev`، پروژه روی آدرس `http://localhost:3000` در دسترس است.
