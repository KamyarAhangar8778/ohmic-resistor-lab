**مجموعه ابزارهای تعاملی و دقیق برای محاسبات قطعات و مدارهای الکترونیکی**

اوهمیک با هدف حذف محاسبات دستی تکراری و تسریع فرآیند طراحی مدار ساخته شده است. این پروژه امکان انتخاب سریع مقادیر استاندارد تجاری، مشاهده رفتار فرکانسی و بررسی اثر بار واقعی را در یک رابط کاربری مدرن و تاریک فراهم می‌کند.

---

## ویژگی‌های اصلی

### ۱. مقاومت‌های موازی
- محاسبه دقیق مقاومت معادل ($R_{eq}$) و هدایت کل مدار بر پایه مفهوم رسانایی (Conductance)
- پشتیبانی از تعداد دلخواه شاخه با واحدهای $\Omega$، $\text{k}\Omega$ و $\text{M}\Omega$
- نمایش سهم جریان هر شاخه به صورت درصد
- شماتیک برداری تعاملی با دو استاندارد **IEEE** (زیگزاگ) و **IEC** (مستطیل)
- هشدار هوشمند وضعیت اتصال کوتاه

### ۲. مقسم ولتاژ (Voltage Divider)
- حل مستقیم و معکوس برای یافتن $R_1$ و $R_2$ بر اساس ولتاژ ورودی و خروجی هدف
- پیشنهاد خودکار جفت‌مقاومت‌های استاندارد سری‌های **E24** و **E96**
- رتبه‌بندی پیشنهادها بر اساس کمترین خطای ولتاژ یا کمترین تلفات توان
- پشتیبانی از مقاومت بار ($R_L$) و رسم منحنی افت ولتاژ تحت بار
- نمایش کد رنگی مقاومت‌ها و امکان خروجی برای ابزارهای EDA

### ۳. فیلترهای پسیو فرکانسی (RC / RL)
- محاسبه فرکانس قطع ($-3\,\text{dB}$)، ثابت زمانی ($\tau$) و زاویه فاز
- رسم دیاگرام بود (Bode Plot) دامنه و فاز در بازه ۴ دهه فرکانسی
- پیشنهاد نزدیک‌ترین قطعات تجاری استاندارد به فرکانس قطع مورد نظر
- شماتیک لحظه‌ای مدار فیلتر

## نصب و اجرا

```bash
# کلون کردن مخزن
git clone https://github.com/KamyarAhangar8778/ohmic-resistor-lab.git
cd ohmic-resistor-lab

# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev
```

پس از اجرا، پروژه در آدرس [http://localhost:3000](http://localhost:3000) در دسترس است.

## ساختار پروژه (خلاصه)

```
ohmic-lab/
├── app/                    # صفحات و layout اصلی (App Router)

│   └── e-series.ts         # سری‌های استاندارد E24 / E96
├── types/                  # تعاریف TypeScript
├── hooks/                  # هوک‌های سفارشی
└── public/                 # فونت‌ها و دارایی‌های استاتیک
```
