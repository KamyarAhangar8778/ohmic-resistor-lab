# محاسبه‌گر مقاومت موازی و شماتیک‌ساز مدار (Parallel Resistor Calculator)

یک ابزار تحت وب مهندسی الکترونیک برای محاسبه سریع مقاومت معادل ($R_{eq}$)، رسانایی مدار ($G$) و تحلیل توزیع جریان در اتصالات موازی به همراه شماتیک تعاملی EDA.

---

## 🌟 امکانات و قابلیت‌های کلیدی

1. **محاسبه مقاومت معادل مدار موازی**:
   - پشتیبانی از تعداد نامحدود شاخه‌های مقاومت با امکان تعیین تعداد یکسان از هر مقاومت.
   - تبدیل خودکار واحدهای اهم ($\Omega$)، کیلواهم ($\text{k}\Omega$) و مگااهم ($\text{M}\Omega$).
   - نمایش مقدار دقیق تا ۲ رقم اعشار و مهندسی استاندارد.

2. **شماتیک تعاملی و زنده مدار (EDA Schematic)**:
   - رسم خودکار شماتیک اتصال موازی با هماهنگی آنی با مقادیر وارد شده.
   - قابلیت جابه‌جایی استاندارد نمادها بین **ANSI/IEEE** (زیگزاگ) و **IEC** (مستطیل اروپایی).
   - شبیه‌سازی انیمیشن شارش الکترون‌ها در ریل‌های مثبت و منفی و شاخه‌های مدار.
   - محاسبه و نمایش درصد سهم جریان هر شاخه ($I_k$) طبق رسانایی مقاومت.
   - کادر فوکوس و هایلایت مجزای شاخه هنگام هاور.
   - تشخیص و نمایش هشدار بصری اتصال کوتاه ($0\,\Omega$).

3. **مدارهای پیش‌فرض و سناریوهای کاربردی**:
   - دارای الگوهای آماده برای کاربردهای رایج الکترونیک:
     - تقسیم جریان استاندارد (Standard Current Divider)
     - آرایه مقاومت موازی توان بالا (High-Power Resistor Array)
     - مقاومت معادل سنسور و Pull-Up

4. **فرمول و مراحل گام‌به‌گام**:
   - نمایش کامل مراحل فرمول $\frac{1}{R_{eq}} = \sum \frac{1}{R_n}$ همراه با محاسبه مجموع رسانایی مدار ($G$).

## 🛠️ پشته فناوری (Tech Stack)

- **فریم‌ورک**: [Next.js 15+](https://nextjs.org/) با معماری App Router
- **زبان**: [TypeScript 5](https://www.typescriptlang.org/)
- **استایل‌دهی**: [Tailwind CSS v4](https://tailwindcss.com/)
- **آیکون‌ها**: [Lucide React](https://lucide.dev/)
- **فونت**: وزیرمتن (Vazirmatn) + فونت مونواسپیس برای ارقام مهندسی

## 🚀 راه‌اندازی و توسعه محلی

برای اجرای پروژه روی سیستم محلی:

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه پروداکشن
npm run build

# بررسی کدهای پروژه با لینتر
npm run lint
```

سرور روی پورت `http://localhost:3000` در دسترس خواهد بود.
